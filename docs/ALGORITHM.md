# アルゴリズム
WeVocalSynth の音声処理（ピッチ変更・時間伸縮・フォルマント補正・解析・合成）が、どういう考え方で動いているかをまとめる。コードを読む前に全体の仕組みをつかむためのもの。細かい値や実装の工夫は、各ファイルの先頭のコメントにある。(2026-10-04 時点)

関連: [アーキテクチャ](ARCHITECTURE.md) / [決定事項](DECISIONS.md) / [ボーカル抽出](EXTRACTOR.md)

## 用語

| 用語 | 意味 |
| --- | --- |
| 時間伸縮（タイムストレッチ） | 音の高さを変えずに、長さだけを変えること |
| ピッチ変更（ピッチシフト） | 長さを変えずに、音の高さだけを変えること |
| リサンプル | 音声を別の速さで読み直すこと。速く読むと短く高く、遅く読むと長く低くなる |
| F0（基本周波数） | 声の高さ。1 秒あたりの声帯の振動回数（Hz） |
| フォルマント | 声のスペクトルの山の並び。母音や声質（太さ・細さ）を決める |
| スペクトル包絡 | スペクトルの細かい凹凸（倍音）をならした、なだらかな形。フォルマントはこの山 |
| オーバーラップ加算 | 短い断片を窓（端が 0 になる重み）で切り出し、少しずつ重ねて足し合わせること |
| STFT / FFT | 音声を短い区間ごとに周波数成分に分けること / それを速く計算する方法 |

## 全体の流れ

ピッチ変更は「時間伸縮」と「リサンプル」の組み合わせで行う（`dsp/src/pipeline.rs`）。

1. 音声を「伸縮率 × ピッチ比」の倍率で時間伸縮する（長さが変わり、高さは変わらない）
2. フォルマントを保持するときは、伸縮した音声のスペクトル包絡を補正する（[フォルマント補正](#フォルマント補正)）
3. ピッチ比の速さでリサンプルし、目的の長さに戻す（高さがピッチ比の分だけ変わる）

たとえば 1 オクターブ上げるときは、2 倍に伸ばしてから 2 倍速で読み直す。長さは元に戻り、高さだけが 2 倍になる。

そのため、処理方式（次の節）はピッチの変更と長さの変更の両方に反映される。ピッチだけを変えるときも、中ではピッチ比の分だけ選んだ方式で伸縮している。ピッチと長さで別々の方式は選べない（1 回の伸縮にまとめているため）。

リサンプルは、窓付き sinc 補間で行う（`wevocal-lib/src/resample.rs`）。速く読むときはカットオフを下げて、折り返しノイズ（高い音が低い音に化けること）を防ぐ。

## 処理方式（時間伸縮）

処理方式は 10 個から選べる（v2・v3 は改良版で、従来版も残している。改良版がある SOLA・PSOLA・WSOLA は、設定で表示したときだけ選択肢に表示する）。どれも時間伸縮の方式で、上のとおりピッチの変更にも使う。どれも「出力の各位置が、入力のどこに当たるか」という時間の対応（`timemap.rs`）に沿って、入力から断片を取ってきて並べ直す。一定の倍率の伸縮も、時間ごとに倍率が変わる伸縮（ピッチカーブ）も、同じ仕組みで扱う。

| 方式 | ファイル | 仕組み | 向いているもの |
| --- | --- | --- | --- |
| PSOLA | `psola.rs` | 声の 1 周期ごとに切り貼りする | 声 |
| SOLA | `sola.rs` | 約 50ms の断片を、短いクロスフェードでつなぐ | 声・単音 |
| SOLAv2 | `sola2.rs` | 声のある所は 1 周期ずつの断片を、SOLA と同じ短いクロスフェードでつなぐ | 声。大きく伸ばすとき |
| SOLAv3 | `sola2.rs`（`stretch_clean`） | SOLAv2 で、前後約 3 周期を平均して混ぜる | 声（ボーカルの既定）。整った滑らかな声にしたいとき |
| WSOLA | `wsola.rs` | 約 46ms の断片を、半分ずつ重ねてつなぐ | 子音の多い音声。速い |
| PSOLAv2 | `psola.rs`（`Marking::Correlation`） | PSOLA の目印を、前の周期と最も似ている位置に配置する | 声 |
| WSOLAv2 | `wsola.rs`（`wsola2_map`） | WSOLA の位置合わせを、正規化した相互相関で行う | 子音の多い音声 |
| Phase Vocoder | `pv.rs` | 周波数成分ごとに位相をそろえて伸ばす | 和音・楽器（楽器の既定） |
| Phase Vocoder v2 | `pv.rs`（`stretch_map2`） | Phase Vocoder で、立ち上がりのまわりだけ伸ばさずに進める | 打楽器・ピアノなど立ち上がりのある音 |
| HPSS | `hpss.rs` | 打楽器の成分と伸びる成分に分け、別々の方式で伸ばして加える | ドラム入りの曲。重い |

画面では方式名の代わりに愛称を表示する（`src/i18n/*.json` の `algorithm.*`）。コードとこのドキュメントでは方式名を使う。

| 方式 | 画面の名前 |
| --- | --- |
| SOLA / SOLAv2 / SOLAv3 | Legacy Solis / Solis / Vesola |
| PSOLA / PSOLAv2 | Legacy Pisol / Pisol |
| WSOLA / WSOLAv2 | Legacy Wevia / Wevia |
| Phase Vocoder / Phase Vocoder v2（以前の画面の名前は PhaseV / PhaseV v2） | Phasera / Phasera v2 |
| HPSS | HPSS |

「Legacy」が付く方式は、改良版がある従来の方式。既定では選択肢に表示しない（設定の「従来の処理方式も表示する」）。

ステレオでは、全チャンネルで同じ切り貼りの位置を使う。チャンネルごとに位置がずれると、音の定位（左右の位置）が崩れるため。

### PSOLA（Pitch-Synchronous Overlap-Add）

1. 声の 1 周期ごとに目印（ピッチマーク）を配置する。前の目印から約 1 周期先の、波形の山を探す
2. 目印を中心に、2 周期分を窓で切り出す
3. 出力の位置に合わせて、断片を 1 周期ずつずらして重ねる。伸ばすときは同じ断片を繰り返し、縮めるときは間引く

周期の区切りで切り貼りするので、伸ばしても声の周期の形が崩れにくい。息や子音など周期のない部分は一定間隔で切り出し、同じ断片の繰り返しがブザー音にならないよう、切り出す位置を少しずつずらす。

#### PSOLAv2（目印の置き方の改良）

従来の PSOLA は、予定位置の前後 ±30% で「いちばん大きいサンプル」を目印にしている。声の波形には同じくらいの高さの山が 1 周期に複数あることが多く、選ぶ山が周期ごとに入れ替わると、切り出す位相がずれてかすれた音になる。

PSOLAv2 は、声が続いている間は、前の目印を中心にした 1 周期分の波形と、候補の位置を中心にした波形の正規化相互相関が最大になる位置を目印にする。周期ごとに同じ位相の位置にそろう。声の始まりは比べる前の周期がないので、従来どおり最も大きい山にする。

TD-PSOLA の音質は目印（声門閉鎖の時点、GCI）の正確さで決まるとされ、候補を推定したピッチとの一致度で選ぶ方法や、自己相関・相互相関を組み合わせる方法が提案されている（[参考にした資料](#参考にした資料)）。PSOLAv2 はそのうち、前の周期との相互相関で揃える部分だけを取り入れた簡単なもの。

**破裂音**: 声のない所は 5ms ごとに切り出すので、伸ばすと同じ破裂が何度も切り出されて二重になった（合成の「た」の繰り返しの ×3 で、破裂のかたまりの数 2.17）。SOLAv2 と同じく、声のない所の立ち上がりは、予定の時刻が届いたら立ち上がりから 15ms を等速で 1 回だけ読み、届く前は立ち上がりにかからない所から切り出し、読み終えたあとは立ち上がりより前に戻らない（同じ所を繰り返すとブザー音になるので、少しずらす）。かたまりの数は ×2、×3 とも 1.00 になった（2026-10-04）。従来の PSOLA は変えていない。

### SOLA と WSOLA

どちらも、入力から一定の長さの断片を取ってきて、前の断片とつながりのよい位置を探して重ねる。

- **SOLA**: 重なりが短い（約 10ms）。重なる区間の 2 乗誤差が最も小さい位置を探す。にじみが少ない
- **WSOLA**: 断片の半分を重ねる。波形が最も似ている位置を探す。なめらかだが、少しにじむ

探す幅は約 12ms。約 83Hz までの低い声の、1 周期分をカバーする。

#### SOLAv2（1 周期ずつの切り貼りと、隣の周期との混ぜ合わせ）

SOLA は約 50ms の断片を繰り返すので、伸ばすと断片の中の立ち上がりや揺れがまとめて二重になり、×4 などではガサガサする。SOLAv2 は次のようにする。

1. F0（`f0.rs`）で声があると分かった所の断片を 1 周期にし、探す幅を ±半周期にする。声のない所は 12ms の固定長
2. 声のある所は、選んだ周期と隣の周期（予定位置の側。波形全体の 2 乗誤差で位置をそろえる）を、予定位置までの近さに応じた割合で混ぜる。1 周期にしただけだと、×4 では同じ周期を 4 回ほど繰り返してから次の周期へ飛び、その飛び目がブツブツと聞こえる。混ぜると周期の形が少しずつ移り変わる（音声符号化の波形補間と同じ考え方）。隣の周期が入力の範囲に収まらない先頭・末尾では混ぜない
3. 声のない所で同じ断片を繰り返すときは、1 回おきに逆向きに読む（同じ雑音の繰り返しが音程のある雑音になるのを防ぐ。Moulines & Charpentier 1990）

つなぎ方（最大 5ms の sin カーブのクロスフェード、2 乗誤差での位置合わせ）は SOLA と同じ。

試したこと（2026-10-03、歌声のサンプルを ×2・×4 に伸ばして聴き比べ）:

| 試したもの | 結果 |
| --- | --- |
| 子音・音の切り替わりを伸ばさず、母音を多めに伸ばす（SOLA の 50ms のまま） | 悪化した。参考にした他ソフトの出力も、切り替わりは等倍ではなく全体と同じ倍率で伸びていた |
| 断片を 15〜20ms にする | 違いが分からない程度 |
| 断片を 3 周期前後（約 12ms）にする | 変な音が入る。同じ数周期の繰り返しで、その長さの周期の低いうなりが生じるため |
| 断片を 2 周期にする | 悪い |
| 断片を 1 周期にする | だいぶ良くなった。ただし、まだブツブツ感は残る |
| ＋声のない所を 1 回おきに逆向きにする | あまり変わらない（このサンプルは 9 割以上が声のある所のため） |
| ＋隣の周期と混ぜる | 他ソフトの出力にだいぶ近くなった（今の SOLAv2） |

**SOLAv3（SOLAv2 の改良版）**: 他ソフト（V 方式）の出力は、原音より周期的で滑らかだった（定常部分の粗さ: 原音 0.0069、他ソフト 0.0027）。こちらは元の波形を残すぶん、原音に近い。そこで、混ぜる周期を隣の 1 つから前後約 3 周期（三角の重み）に広げた版を別に用意した。混ぜる周期の位置は、すべて中心の周期の波形に合わせる（隣どうしで合わせると、外側の周期ほどずれがたまって震えて聞こえるおそれがある）。周期ごとの揺らぎや息のノイズが平均で打ち消し合い、定常部分の粗さは 0.0016 になった（SOLAv2 は 0.0023。いずれも ×2、2026-10-03）。等倍でも平均をかける。元の声らしさを残したいときは SOLAv2、整った声にしたいときは SOLAv3 を選ぶ。

**破裂音（声のない所の立ち上がり）**: 声のない所は 12ms の断片を繰り返す（1 回おきに逆向き）ので、破裂音（6ms ほどの短い雑音）が断片の中に何度も入り、二重・三重に聞こえた。合成の「た」の繰り返し（`tests/consonant.rs`）で、破裂のかたまりの数が ×2 で 2.00、×3 で 2.83 だった。そこで、声のない所の立ち上がり（1ms ごとのエネルギーが直前 10ms の平均の 10 倍を超える所）は、予定の時刻に最も近いブロックで、立ち上がりの少し手前から 15ms を等速で 1 回だけ読む。読み終えたあとは立ち上がりより前に戻らず、まだ鳴らしていない立ち上がりを手前のブロックで先に鳴らさない。かたまりの数は ×2・×3 とも 1.00、立ち上がりの鋭さは 0〜0.5ms になった（2026-10-03）。SOLAv3 も同じ。

**調整できる値の比較**（`sola2::Params`、`tests/sola_params.rs`。普段は動かさない。2026-10-03）: 声のない所のブロックの長さ（8〜20ms）、クロスフェードの最大の長さ（3〜8ms）、声のない所の探索幅（3〜10ms）、立ち上がりを等速で読む長さ（10〜20ms）の組み合わせ 108 通りを、合成音で測った。

| 指標 | 信号 | 結果 |
| --- | --- | --- |
| 周期のきれいさ（1 に近いほどよい） | ビブラート付きの母音、×4 | どの組み合わせも 0.9995〜0.9996 |
| 破裂のかたまりの数・立ち上がり | 「た」の繰り返し、×3 | どれも 1.00、0〜0.3ms |
| 雑音の音程感（2〜30ms のずれでの自己相関の最大。0 に近いほどよい） | 白色雑音、×3 | ブロック 8ms: 0.169、12ms（今の値）: 0.111、16ms・フェード 3ms: 0.102 |

探索幅と、立ち上がりを読む長さは、結果に影響しなかった（声のない所は繰り返すときに位置合わせをしないため）。合成音では差がほとんどつかないので、値は変えていない（ブロック 12ms、フェード 5ms、探索幅 6ms、立ち上がり 15ms）。実際の声で詰めるときは、このテストに声の素材を加えて比べる。

#### WSOLAv2（類似度の正規化）

従来の WSOLA は、前の断片の自然な続きと候補の内積（正規化しない相互相関）が最大になる位置を選ぶ。内積は波形が似ているかだけでなく音の大きさにも比例するので、「似ている位置」より「大きい位置」が選ばれやすく、位置合わせがずれて、にじみ・うなりになる。

WSOLAv2 は、内積を候補のエネルギーの平方根で割った値（正規化した相互相関。自然な続きの側は探索中に変わらないので割らなくてよい）で選ぶ。WSOLA の元の論文は、自然な続きと最もよく似た位置を、相互相関などの類似度で選ぶものとしている（[参考にした資料](#参考にした資料)）。

**破裂音**: 断片が約 46ms と長く半分ずつ重なるので、伸ばすと同じ破裂がいくつもの断片に入って二重になった（×3 でかたまりの数 1.83）。SOLAv2 と同じく、立ち上がりが断片に収まる最初の断片で、立ち上がりが予定の時刻に来る位置から読み、立ち上がりから 15ms を読み終えるまでは前の断片の続きを読む（続けて読むので、重なった断片どうしは元の音と同じになる）。それより前の断片は立ち上がりにかからない位置に、後の断片は立ち上がりより後ろにする。かたまりの数は ×2、×3 とも 1.00 になった（2026-10-04）。従来の WSOLA は変えていない。

このテストのずれ（入力の時刻 × 倍率との差）は、WSOLA では ×3 で平均 +50ms になる。最後の断片が入力の最後に来るよう全体を少し縮めて対応させるためで（TimeMap::frame_pos。断片が長いほど大きい）、母音も同じだけずれるので、音の並びは崩れない。前は二重になった早いほうの破裂を拾っていたので、小さく見えていた。測るときは、低い母音を小さくするため隣のサンプルとの差の振幅を使い、遅れても拾えるよう後ろを広く見る。

### Phase Vocoder

1. 音声を STFT で周波数成分に分ける
2. 出力のフレーム間隔に合わせて、各成分の位相（波のずれ）を進め直す
3. 逆 FFT で音声に戻し、重ねて加える

位相の進め方は identity phase locking（Laroche & Dolson）を使う。スペクトルの山の位相だけを計算し、周りの成分はその山と同じだけ回す。成分ごとにばらばらに回すより、残響のような感じ（フェージー感）が少ない。断片を繰り返さないので大きく伸ばしてもなめらかだが、音の立ち上がりは少しにじむ。

#### Phase Vocoder v2（立ち上がりの保持）

伸ばすと、立ち上がりを含む分析フレーム（約 46ms の窓が重なり合ったもの）が出力の別々の場所に配置され、立ち上がりが前後に広がって聞こえる。位相をそろえるだけではこれは直らない（立ち上がりの山の位相だけを入力に戻す形をまず試したが、効果がなかった）。

Phase Vocoder v2 は次のようにする（`detect_onsets` / `keep_transients`）。

1. 入力のスペクトルの増え方（スペクトルフラックス）が、平均 + 1.5 × 標準偏差を超えて前後より大きいフレームを探す。フラックスが最大になるフレームは前後に 2 フレームほどぶれるので、その窓の範囲で 32 サンプルごとの音量が最も増えた所を立ち上がりの位置にする
2. 各立ち上がりを、元の時間の対応どおりの出力時刻に配置する（その時刻に窓の中ほどが来るフレームを決める）。その前後 2 フレームずつは、入力も出力と同じ幅で進める（伸ばさない）。区間の最初のフレームで位相を入力のものに戻すので、区間の中はほぼ元の波形になる
3. 区間と区間の間は、前の区間の終わりと次の区間の始まりを直線でつなぐ

最初は 3 を「伸ばさなかった分を、区間の外で少しずつ取り戻す」形にしていたが、取り戻しきれないうちに次の立ち上がりが来ると、ずれが溜まって続けて鳴るドラムがだんだんずれた。立ち上がりの時刻を固定する今の形では、8 回/秒の音を 1.5 倍に伸ばしたときのずれが最大 0.1ms（`transient_timing`）。

短い減衰音の連続を 2 倍に伸ばしたテストでは、立ち上がりのまわり ±60ms のエネルギーのうち最も強い 5ms に集まる割合が、Phase Vocoder 0.41 → v2 0.95 になった（`tests/stretch.rs` の `transient_sharpness`、2026-10-02）。区間に入るところで全成分の位相を戻すので、伸びている和音の成分も一瞬つながりが変わる。Röbel の方式は、山ごとに群遅延で立ち上がりかどうかを判定して、立ち上がりの山だけを扱うことでこれを避けている。

#### 方式ごとの立ち上がりの時刻のずれ

8 回/秒の短い減衰音を 1.5 倍に伸ばし、各音のピークが元の時刻からどれだけずれるかを測った（`transient_timing`、2026-10-02）。

| 方式 | 最大のずれ |
| --- | --- |
| Phase Vocoder v2 / PSOLA / PSOLAv2 / HPSS | 0.1〜2.2ms |
| Phase Vocoder | 約 19ms（にじんでピークが定まらない） |
| SOLA / WSOLA / WSOLAv2 | 約 21〜34ms（断片の切り貼りで、立ち上がりが二重になったり前後に動いたりする） |

どれもずれは溜まらず、音ごとに散らばる。SOLA・WSOLA にも Phase Vocoder v2 と同じ「立ち上がりの時刻を固定し、まわりを伸ばさない」仕組みは入れられるが、声の途中で伸ばし方が急に変わり、にじみの少なさが崩れるおそれがあるので入れていない。打楽器の素材は Phase Vocoder v2・HPSS を使う。（PSOLA 系が正確なのは、テストの音が音程のある減衰音で、周期で切り貼りしやすいため。雑音っぽい本物のドラムではここまでにならない見込み）

### 往復の劣化（可逆性）
+3 半音のあと -3 半音、×2 のあと ×0.5 で、どれだけ元の音に戻るかを方式ごとに測った（`tests/roundtrip.rs`、2026-10-04）。位相がずれても同じ音なので、振幅スペクトル（5kHz 未満、元の音の強い所）の対数の差の平均（dB）で比べる。0 に近いほど元に戻っている。「×3」は ±3 半音の往復を 3 回くり返したもの。

測り方の注意:
- SOLA 系は全体が少しずれるので、±50ms のうち最も近い所と比べる
- 雑音は鳴らし直すと bin ごとの強さがでたらめに変わるので、前後 2 bin と前後 1 フレームでならしてから比べる。ならしても、同じ強さの別の白色雑音どうしは 1.9dB になる（雑音を作り直す方式は、雑音の所でこれくらいの差が生じる）

| 方式 | 母音 ±3 | 母音 ×2/×0.5 | 母音 ±3 ×3 | 「た」 ±3 | 「た」 ×2/×0.5 | 「た」 ±3 ×3 |
| --- | --- | --- | --- | --- | --- | --- |
| WSOLA | 0.17 | 0.24 | 0.31 | 3.24 | 2.95 | 23.36 |
| WSOLAv2 | 0.19 | 0.29 | 0.32 | 0.87 | 0.85 | 1.76 |
| SOLA | 0.24 | 0.39 | 0.54 | 0.71 | 0.97 | 3.00 |
| SOLAv2 | 0.08 | 0.14 | 0.14 | 0.66 | 0.59 | 0.91 |
| SOLAv3 | 0.11 | 0.12 | 0.23 | 0.75 | 0.63 | 1.05 |
| PSOLA | 0.28 | 0.21 | 0.49 | 1.88 | 2.00 | 3.80 |
| PSOLAv2 | 0.28 | 0.23 | 0.44 | 0.77 | 1.89 | 1.06 |
| Phase Vocoder | 0.17 | 0.41 | 0.42 | 0.78 | 1.20 | 1.28 |
| Phase Vocoder v2 | 0.17 | 0.41 | 0.42 | 0.93 | 0.77 | 2.13 |
| HPSS | 0.23 | 0.43 | 0.51 | 1.95 | 1.98 | 3.80 |
| SMS（試作） | 0.17 | 0.17 | 0.45 | 1.82 | 1.64 | 2.66 |

今の方式では SOLAv2 が最も元に戻り、くり返してもほとんど増えない（元の波形の周期をそのまま使うため）。

#### SMS（試作。愛称は Specraw。できるだけ可逆な方式の候補）
`sms.rs`。目的は、曲そのもの（和音や伴奏を含む）のピッチを変えても劣化しにくいこと。音を、ゆっくり変わる正弦波の集まり（周波数と振幅の軌跡）と、残りの雑音（48 の帯域ごとの強さ）に分け、出力の時刻に対応する入力の時刻の値で鳴らし直す（Serra & Smith の Spectral Modeling Synthesis）。倍音に限らないので和音や楽器にも使え、鳴らし直した音をもう一度分けるとほぼ同じ値になるので、誤差がたまりにくいと見込んだ。画面ではまだ選べない（`Algorithm::Sms`、番号 10）。

分けて鳴らし直すだけ（`sms_identity`）の誤差と、分かったこと（2026-10-04）:

| 試したこと | 母音 | 「た」 | 白色雑音 |
| --- | --- | --- | --- |
| 正弦波だけ、窓 4096 | 1.15 | 6.54 | — |
| 窓 2048 にする | 0.34 | 5.07 | — |
| 雑音を加える（短い軌跡は雑音として扱う） | 0.17 | 1.54 | 1.62 |
| 振幅を山の高さでなく、山のまわりのエネルギーから求める | 0.12 | 1.51 | 1.17 |

- 窓が長い（4096）と、ビブラートで周波数が窓の中で動いて山が広がり、振幅を小さく見積もった。高さで求めても同じことが起き、鳴らし直すたびに小さくなって誤差がたまった
- 雑音は別の雑音として作り直すので、「た」の子音や息の所は、測り方の下限（約 1.9dB）に近い差が残る

まだ SOLAv2 に及ばず、くり返すと増える（母音 0.17 → 0.45）。次に試すなら、ピッチの変更を伸縮とリサンプルではなく正弦波の周波数をそのまま変えて行う、軌跡のつなぎ方を見直す、雑音を元の残差から作る、など。
### HPSS（打楽器分離のハイブリッド）

Driedger・Müller・Ewert (2014) の方式。立ち上がりを見つける代わりに、音を分けることで暗に扱う（`hpss.rs`）。

1. STFT（約 46ms、75% 重ね）の振幅を、時間方向（17 フレーム）と周波数方向（17 ビン）にそれぞれメディアンフィルタする。持続する音はスペクトログラムで横に伸びるので時間方向のほうが大きく残り、打楽器は縦に伸びるので周波数方向のほうが大きく残る
2. 大きく残ったほうに各成分を振り分け（2 値のマスク）、「伸びる成分」と「打つ成分」の 2 本の音に戻す。マスクはモノラルにまとめた音で決め、全チャンネルに使う（定位を崩さない）
3. 伸びる成分は Phase Vocoder、打つ成分は約 10ms の短い窓のオーバーラップ加算（位置合わせなし）で伸ばし、足し戻す

Phase Vocoder は立ち上がりがにじみ、短い窓の OLA は伸びる音がうなるので、それぞれ得意なほうに任せる形。全体の STFT を持つとメモリが大きい（3 分のステレオで数百 MB）ので、時間方向のメディアンに要る前後 17 フレーム分だけを持ちながら順に処理する。

テスト（`tests/stretch.rs`、2026-10-02）では、分けた 2 本を加算すると入力と一致し、持続音は伸びる成分、クリックは打つ成分に入る（`hpss_separation`）。短い減衰音の立ち上がりの集中度は Phase Vocoder 0.41 → HPSS 0.67（Phase Vocoder v2 は 0.95）。分離の分だけ重く、3 分のステレオを 2 倍に伸ばすのに約 17 秒かかる（Phase Vocoder は約 6 秒。ネイティブ、開発 PC）。

## フォルマント補正

リサンプルは、フォルマントを含むスペクトル全体を一緒に動かしてしまう。そのままだとピッチを上げた声が細く（子どもっぽく）なる。そこで、リサンプルの **前** にスペクトル包絡を逆向きに変形しておき、リサンプル後に元の包絡に戻るようにする（`formant.rs`）。

1. フレームごとに対数スペクトルを求める
2. ケプストラム（対数スペクトルをもう一度周波数分解したもの）で細かい凹凸を取り除き、包絡 E(f) を求める
3. 包絡が E(c·f) になるように、周波数ごとの倍率を掛ける。c = ピッチ比 ÷ フォルマント比
4. リサンプルでスペクトルがピッチ比の分だけ動くと、包絡は E(f ÷ フォルマント比) になる

フォルマント比が 1 なら元の包絡のまま（保持）、1 以外なら声質だけが変わる。包絡の凹凸を取り除く幅は、フレームごとの声の周期に合わせて変える。低い声でも高い声でも、倍音だけを取り除けるようにするため。

フォルマントパネルで描いた曲線は、フレームごとに c を変えて同じ処理を行う（`formant::correct_varying`）。ピッチは変えない。

## ピッチカーブ編集

ピッチパネルで描いた目標のピッチは、時間ごとに変わるピッチ比 r(t) にして処理する（`curve.rs`）。

1. 入力の各時刻 t を r(t) 倍に伸ばす。伸ばした音声の中で、時刻 t は τ(t) = ∫r dt の位置に来る
2. 伸ばした音声を、位置 τ(t) から読み戻す（リサンプル）

長さは元のまま、時刻 t の高さだけが r(t) 倍になる。一定のピッチ変更と同じ「伸縮 → リサンプル」を、倍率が時間で変わる形に広げたもの。

画面側（`src/audio/pitchTools.ts`）の「平らにする」「音階に揃える」「ビブラート」「MIDI の音程を当てはめる」は、どれもこの目標のピッチの曲線を作るだけで、音声は「適用」のときにこの処理で作る。

## 解析

### F0 推定（YIN 法）

声の高さを 10ms ごとに推定する（`f0.rs`）。計算を軽くするため、16kHz に間引いてから行う。

1. 波形と、それを少しずらした波形との差（差分関数）を、ずらし幅ごとに求める
2. 差を、それまでの平均で割って正規化する
3. 正規化した差が閾値を下回った最初の谷を、1 周期とみなす

谷が浅い（はっきりした周期がない）フレームと、音が小さいフレームは、声がない（無声）として 0 にする。判定の厳しさと無音の閾値は、「設定」→「処理」→「ピッチ解析」で変えられる。

### テンポ解析

BPM と 1 拍目の位置を推定する（`tempo.rs`）。

1. 短い区間ごとにスペクトルを求める
2. 各周波数で振幅が増えた分だけを足し合わせ、時刻ごとの「音の増え方」（オンセット強度）にする。音は主に拍の頭で鳴り始めるため
3. オンセット強度の、時間方向の周波数成分を BPM の候補ごとに求める。120 BPM なら 2Hz の成分が大きくなる
4. 選んだ BPM の成分の位相（波の山の位置）から、1 拍目の位置を求める

いちばん強い成分は、正しいテンポの 2 倍や半分になりやすい。そのため候補を強い順に複数返し、画面で選び直せるようにしている。

候補の BPM は、まず 0.1 刻みで探してから詰める（`refine`）。基本の成分のピークは幅が広く（20 秒の素材で数 BPM）、端で切れることによる漏れでずれるので、オンセット強度に Hann 窓をかけたうえで、まわり ±0.6 BPM を 0.01 刻みで、拍の速さの成分と 2〜4 倍の成分（倍音）の大きさの和が最大の所を探し、放物線で補間する。倍音は同じずれでもピークの位置が大きく動くので、細かく決まる。以前は基本の成分だけで、138 BPM の曲が 137.4 になるなど 0.5 ほどずれることがあった（2026-10-02）。

### スペクトログラム

表示用に、STFT の振幅を dB にして、対数の周波数軸の 128 段に割り当てる。1 段 1 バイト（0〜255）に詰めて、メモリを抑える。計算は追加機能「解析」（analyzer/ の `dsp/src/spec.rs`）が行う。

### ボーカル / 楽器の自動判定

ファイルを開いたとき、先頭の数十秒で F0 が取れたフレームの割合を見る（`src/audio/detectMode.ts`）。単音の声や楽器はピッチが取れやすく、和音やドラムは取れにくい。割合が高ければボーカル（SOLAv3 ＋ フォルマント保持）、低ければ楽器（Phase Vocoder）にする。

## 和音を 2 つの声に分ける（試験的機能）
`voices.rs`。ボーカルの和音（主旋律とハモリなど）を、高い方と低い方、または大きい方と小さい方の 2 つに分ける。学習済みのモデルは使わない（2026-10-05）。

1. STFT（窓 4096、間隔 512）のフレームごとに、白色化したスペクトル（周波数に比例した幅でならした大きさで割る）で、倍音の振幅の重み付きの和（顕著さ）が最大の F0 を選ぶ（Klapuri 2006 の重み）
2. その声の倍音を、スペクトルの滑らかさで抑えてから差し引き、残りからもう 1 つ選ぶ（Klapuri 2003）。1 つ目の ±60 セントは選ばない。顕著さが 1 つ目の 25% 未満なら 1 声とみなす
3. 2 つの声の倍音のうち、もう一方の声の倍音と 1.5 ビン以内で重なるものは、同じ声の重ならない前後の倍音から直線で補った振幅にする（5 度、8 度向け）
4. 前のフレームの F0 に近い方へつないで 2 つの軌跡にし、高さ（フレームごと）か音量（前後 8 フレームでならした倍音の大きさ）で A、B に振り分ける
5. 各声の倍音の見込みの比のソフトマスクで分け、元の位相のまま戻す。マスクの和は 1 なので、A + B は元の音と一致する

白色化がないと、フォルマントの近くの倍音に引っ張られて 1 オクターブ上を選び、2 つ目も同じ F0 になった（2 つとも見つかったフレーム 0% → 白色化と ±60 セントの除外で 100%）。

合成の 2 声（220Hz 付近、±30 セントのビブラート）での SDR（`tests/voices.rs`）:

| 条件 | A | B |
| --- | --- | --- |
| 高さ、3 度 | 13.5 dB | 16.8 dB |
| 高さ、5 度 | 5.9 dB（補う前 3.9） | 8.6 dB（補う前 6.5） |
| 高さ、8 度 | 6.7 dB（補う前 5.0） | 8.4 dB（補う前 6.7） |
| 音量、3 度、片方 -6dB | 19.9 dB | 10.6 dB |
| 音量、交差 | 12.5 dB | 1.9 dB |

実際の素材では、単純な和音なら分けられた（ユーザーの確認）。高さで分けると、声が交差したところで出力が入れ替わる（仕様）。

## 無音で区切る
[audio/silence.ts](../src/audio/silence.ts)（`findSounds`）。10ms ごとに、チャンネルのうち大きい方の RMS を測り、しきい値（既定 -40dBFS）より小さい区間を無音とする。無音が設定の長さ（既定 200ms）より短ければ区切りにせず、前後の音をつなぐ（息継ぎや子音の前の途切れで分かれないように）。50ms より短い音は捨て（クリック音など）、範囲の前後に 10ms の余白を加える（立ち上がりと余韻を切らないように）。
