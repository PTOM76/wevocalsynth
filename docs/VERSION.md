# バージョン履歴
マイナーバージョンごとの主な変更。細かい修正は省く（詳しくは git の履歴とタグ `v1.x.y` を参照）。

## v1.5 (1.4.1 - 1.5.0)
2026-10-04〜

スマホの新しい画面、ミニマップ、キーの割り当て、録音を追加した。スペクトログラムと動画の書き出しは、使用するときだけダウンロードする追加機能にした。

### 画面
- スマホの新しい画面（なぞって範囲を選択し、下に編集のボタンを表示する。両端のつまみ、横向きで右の欄をたたむ）。以前の画面も選べる（1.4.1）
- スマホの ⋮ のメニューを、パソコンのメニューバーと同じ中身にした。トラックの「⋯」でトラックのメニューを開く（1.4.2）
- 波形の下にミニマップを表示する（1.4.3）
- キーボードショートカットの割り当てを、設定の「キーとマウス」で変更できるようにした（1.4.4）
- 複数のウィンドウで別の作業をできるようにした（「ファイル」→「新しいウィンドウ」。自動保存はウィンドウごと。同時に開く数は設定の「全般」で変更できる）（1.4.14）

### 追加機能
- 設定に「追加機能」の分類を作り、ダウンロードと削除をまとめた（1.4.5）
- スペクトログラムを追加機能「解析」で表示する（1.4.4）
- 動画として書き出す（追加機能「変換」。音量波形などの簡易な波形、背景の色と画像、プレビュー）（1.4.6）

### 音声
- 録音して新しいトラックにする（1.4.4）
- 再生する音に上限を設ける（既定はオン、-1dB。設定の「全般」で変更できる）（1.4.12）
- 主旋律、ハモリ、伴奏の 3 トラックに分離する（1.4.3）
- 楽器ごとのトラックに分離する（Demucs。ボーカル、ドラム、ベース、その他の 4 つか、ギターとピアノも分ける 6 つ。ボーカルを主旋律とハモリにも分けられる）（1.4.8）
- FLAC と AAC（M4A）で書き出す。MP3 と Opus は低いビットレート（32〜96 kbps）も選べるようにした（1.4.16）
- 試験的機能: 和音を分ける（1.4.3）、GPUでの並列処理（1.4.4）、声から五十音を作る（1.4.6）

## v1.4 (1.3.1 - 1.4.0)
2026-10-03〜10-04

切り出しと書き出しの流れを整えた。選択範囲の繰り返し、フォルダーへの保存、編集ソフトと同じ形の書き出し、加工のプリセットを追加し、右クリックのメニューをサブメニューにまとめた。テンポが途中で変わる曲に対応し、ボーカル抽出に高品質モデルを追加した。

### 編集
- 選択範囲を繰り返す（元の範囲を含めた回数だけ後ろに並べる）
- 「無音で区切って選択」を追加。選んだあと、件数と次の操作（新しいトラックへ、別々に保存）を通知に表示する
- Tab / Shift+Tab で複数の選択範囲を順に移る。↑↓ で加工のピッチを半音ずつ（Shift で 12 半音）変える
- 選択範囲の長さを拍でも表示する
- 加工のプリセット（ピッチ、長さ、フォルマント、処理方式の組み合わせを保存して呼び出す）
- 「平らにする」の強さを選べるようにした（元の揺れを少し残す）
- 「原音を保持する」設定と「原音からトラックを作成」

### 書き出しと保存
- 書き出しで保存先フォルダーとファイル名を決めて書き出す（Chrome、Edge。フォルダーは覚えておき、同じ名前は上書きを確認する）
- 書き出しにノーマライズと両端のフェードをかけられるようにした
- 範囲を選んで書き出すと、範囲の初期値を「選択範囲」にする。トラックの右クリックから、そのトラックだけを書き出す
- 選択範囲（複数なら別々のファイル）を、書き出し先のフォルダーへ連番の名前で保存する
- 開いた .wvsp や一度保存したファイルには、Ctrl+S で保存先を聞かずに上書きする。「名前を付けて保存」を追加
- 保存していない変更があると、プロジェクト名とタイトルバーに「*」を表示する
- プロジェクトファイルの形式を版 3 にした（加工していないトラックは加工後を書かない）。形式の説明（PROJECT_FORMAT.md）を追加

### テンポ
- マーカーに「ここからのテンポ」を持たせ、テンポが途中で変わる曲に対応した（拍の線、吸着、← →、BPM を使う加工が区間のテンポになる）
- 目盛りの右クリックで、その位置を 1 拍目にする

### 画面
- 波形の右クリックをサブメニュー（選択、編集、音量、ピッチ、新しいトラックへ、ボーカル抽出）にまとめ、「選択範囲を書き出す…」「選択範囲に合わせて拡大」を追加した
- ピッチを波形に重ねて表示、編集する（「表示」→「ピッチを波形に重ねる」）
- 設定に「画面の大きさ」（90〜150%）と「音声の出力先」を追加
- 進み具合を 1 本のゲージにまとめ、押すと一覧で見られるようにした
- 設定の分類をサブアイテムで整理した。「開発者向け」を音声処理と診断に分けた
- スマホの上部バーにプロジェクト名を表示し、通知が再生ボタンを隠さないようにした
- ヘルプにライセンス情報を追加

### 処理方式
- Wevia、Pisol でも、伸ばしたときに破裂音が二重に聞こえないようにした
- フォルマント補正を約 1 割速くした
- 試験的な方式 Specraw（できるだけ可逆な方式の試作）を「開発者向け」で選べるようにした

### ボーカル抽出
- 高品質モデル（ボーカル向け、伴奏向け。UVR の MDX-Net）を追加
- GPU を使用できないとき、CPU に切り替える前に確認する。GPU との接続が切れたら、ブラウザの再起動を勧める
- 抽出のメモリの上限を、診断からボーカル抽出の設定へ移した
## v1.3 (1.2.1 - 1.3.0)
2026-10-03

Vesola をボーカルの既定にし、Solis と Vesola で破裂音が二重にならないようにした。iPhone、iPad でボーカル抽出がメモリ不足で失敗する問題に対応し、追加機能のダウンロードを裏で進められるようにした。

### 処理方式
- ボーカルの既定を Vesola（SOLA v3）にした（1.2.1）
- Solis、Vesola で、伸ばしたときに破裂音が二重に聞こえないようにした（1.3.0）

### ボーカル抽出
- iPhone、iPad でのメモリ不足に対応した。抽出のメモリの上限を下げ、推論の Worker を使い回す（1.2.1〜1.2.10）。上限は「開発者向け」で変えられる
- 「開発者向け」→「ボーカル抽出の診断」を追加（1.2.7〜1.2.9）
- 「メモリを空けてから抽出する」設定と、抽出のあとにタブが落ちたことの検知（1.2.11）
- 端末と非互換のモデルを、抽出のときだけ代わりのモデルに替える（1.2.11）
- 計算の実行環境を GPU 用と CPU 用に分け、要る方だけをダウンロードする（1.2.11）
- GPU に対応しないモデルでは「GPU を使う」を押せなくし、理由を表示する（1.3.0）

### 追加機能
- ダウンロードを裏で進め、ステータスバーに進み具合を表示する（1.2.11）

### その他
- 加工したトラックの原音を IndexedDB に退避し、メモリを節約する（1.2.4）
- 「開発者向け」→「開発版の更新を受け取る」を追加（1.2.10）

## v1.2 (1.1.1 - 1.2.0)
2026-10-02〜10-03

声を大きく伸ばしても荒れにくい Solis と、整った声にする Vesola を追加し、処理方式に愛称を付けた。マーカー、音符ブロック、素材を MIDI に並べる機能など編集の機能を増やし、Chrome や Edge では保存先の選択や最近使用したファイルに対応した。韓国語と中国語にも対応した。

### 処理方式
- Solis（SOLA v2）を追加し、ボーカルの既定にした。声のある所を 1 周期ずつ切り貼りし、隣の周期と混ぜるので、大きく伸ばしても荒れにくい（1.1.7）
- Vesola（SOLA v3）を追加。前後数周期を平均し、息や揺らぎを抑えた滑らかな声にする（1.1.8）
- 改良版がある従来の方式は、既定では選択肢に表示しないようにした（「設定」→「デフォルト」→「従来の処理方式も表示する」）（1.1.8）
- 処理方式の画面上の名前を愛称にした。Solis（SOLA v2）、Vesola（SOLA v3）、Pisol（PSOLA v2）、Wevia（WSOLA v2）、Phasera（PhaseV）、Phasera v2（PhaseV v2）。改良版がある従来の方式は Legacy Solis（SOLA）、Legacy Pisol（PSOLA）、Legacy Wevia（WSOLA）。HPSS はそのまま（1.2.0）

### 編集
- 逆再生と、テンポ変更に合わせて全体を伸縮する機能（1.1.1）
- 選択範囲を新しいトラックへコピー、移動（1.1.1）
- 素材を MIDI の音符に並べる機能（同じ高さの加工結果は使い回す）（1.1.1）
- 「揃えるまでの時間」と、音符ブロックの表示と編集（1.1.1）
- マーカーと、目盛りの右クリックメニュー（1.1.2）。マーカーのドラッグでの移動（1.1.11）
- 空のトラックの追加と、無音の挿入（1.1.3）
- 再生位置の数値入力（1.1.6）
- 波形の縦の拡大（1.1.7）
- 「音程に揃える」を「音階に揃える」に改名。揺れを残すは既定で OFF、揃え方の既定は指定した音（1.1.10）

### 画面と操作
- 韓国語、中国語（簡体字、繁体字）に対応（1.1.1）
- メニューバーに「再生」「トラック」メニューを追加。表示を「レベルメーター」から「音量メーター」に変更（1.1.1）
- トラックごとに表示範囲を覚える（1.1.1）
- サブメニューでメニューを整理（1.1.5）
- ホイールの操作の切り替え（Ctrl+ホイールで拡大縮小するか、ホイールで拡大縮小するか）（1.1.11）

### ファイル
- 保存や書き出しのときに保存先を選ぶ画面を表示し、フォルダを記憶する。最近使用したファイル（Chrome、Edge）（1.1.12）
- インストールしたアプリでファイルをダブルクリックして開ける（1.1.13）。対象は .wvsp のみ（1.1.15）
- 自動保存が OFF のとき、閉じる前に未保存の変更を確認する（アプリとして開いているとき）（1.1.13）
- 最初の画面に最近使用したファイルを表示。ドロップしたファイルや保存したプロジェクトも記録する。書き出しダイアログを別ウィンドウで開いているときも保存先を選べる（1.1.14）

## v1.0 (1.0.1)
2026-09-27〜09-28

最初の公開版。ブラウザだけで、声のピッチや長さを変え、ピッチ曲線を編集して書き出せる。PWA としてオフラインでも使用できる。

### 加工
- ピッチ変更と時間伸縮（WSOLA、PSOLA）
- フォルマントの保持と移動
- ボーカルと楽器の処理モードと、その自動判定
- ループ試聴（スライダーの変更を即座に反映）
- 複数の範囲の一括加工

### 編集
- 基本周波数（F0）の解析と、ピッチ曲線の編集。ビブラート
- 音量の編集
- スペクトログラムの表示

### ファイルと保存
- プロジェクトの保存と読み込み（.wvsp）
- 音声ファイルの書き出し（WAV、MP3、Opus）。MP4、M4A の読み込み
- 作業の自動保存と復元

### 画面と操作
- PWA（オフラインで利用でき、アプリとしてインストールできる）
- メニューバー、右クリックメニュー、アプリ型のレイアウトとインスペクタ
- スマホ対応
- 設定画面
- 日本語と英語に対応
