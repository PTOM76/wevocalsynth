# 要件定義
WeVocalSynth が何を目指し、どこまでできているか。細かい経緯はリポジトリ外の `DEFINE.md` と `TASK.md` にある。

関連: [アーキテクチャ](ARCHITECTURE.md)、[決定事項](DECISIONS.md)

## 概要
ブラウザ上で音声素材のピッチと長さを編集するツール。主な用途はボーカル・音声素材の加工で、インストールせずにブラウザだけで使えることを目指す。

## 方針

| 方針 | 理由 |
| --- | --- |
| インストール不要で、ブラウザだけで動く | 気軽に試せることを優先するため |
| 音声ファイルをサーバーへ送らない | 素材の権利やプライバシーを気にせず使えるようにするため。自動保存もブラウザ内（IndexedDB）に限る |
| 素材の加工で使いやすいこと | 切り貼り、音程合わせ、伸ばしなど、よく使う操作を短い手数でできるようにする |

## 機能

### MVP（完成済み）

| 要件 | 実装 |
| --- | --- |
| 音声ファイルの読み込み | ファイル選択・ドラッグ＆ドロップ。WAV は元のサンプルレートのまま読み込む。MP3 / FLAC などブラウザが対応する形式も可 |
| 波形の表示 | 全体波形・時間軸・再生位置。拡大縮小・スクロール |
| 編集範囲の選択 | ドラッグ、開始・終了の数値入力、端のドラッグで調整 |
| ピッチ変更 | ±24半音、0.01半音単位。長さは変わらない |
| 時間伸縮 | ×0.25〜×8。ピッチは変わらない |
| ピッチ変更と時間伸縮の組み合わせ | 1回の処理で同時に適用できる |
| 加工結果のプレビュー | 通常の再生、範囲の試聴、加工済みプレビュー、リアルタイムのループ試聴 |
| WAV 出力 | 16-bit / 24-bit PCM、32-bit float。元のサンプルレートとチャンネル数を保つ |

### MVP の後に足したもの

| 分類 | 機能 |
| --- | --- |
| 編集 | 切り取り・コピー・貼り付け・選択範囲のみ残す、元に戻す・やり直す（20段）、複数区間編集、音量編集（ゲイン・フェード・ノーマライズ・無音化） |
| ピッチ | 範囲の今の音程の表示と「音程を合わせる」、F0（ピッチ）表示、ピッチカーブ編集（ペンで描く） |
| 音質 | ボーカル／楽器モード（自動判定あり）、フォルマント保持・移動 |
| 表示 | スペクトログラム、原音との比較（加工後／原音の切替） |
| 保存 | プロジェクトの保存・読み込み（.wvsp）、作業の自動保存と次回起動時の復元 |
| その他 | 設定画面、多言語化（日本語・英語）、PC とスマホで別々に設計した画面 |

### 対象外
予定していないもの: 複数トラック編集、EQ・リバーブなどのエフェクト、ノイズ除去、MIDI、マイク録音、アカウント機能、クラウド保存、DAW としての総合的な編集機能。

## 非機能要件

| 項目 | 目標・現状 |
| --- | --- |
| 処理速度 | 数分の音声を現実的な時間で処理する。3分・48kHz・ステレオで、×2 伸長（WSOLA）が約2秒、F0 解析が約1.7秒 (2026-09-27 時点、WASM、開発 PC) |
| 応答性 | 重い処理は Web Worker で行い、画面を止めない。長い処理は進捗を表示する |
| 対応環境 | WebAssembly（SIMD）、Web Audio API、AudioWorklet、IndexedDB に対応したモダンブラウザ（Chrome / Edge / Firefox / Safari の最近の版） |
| 画面 | PC は広い画面を活かした配置、スマホは縦並びで片手で操作しやすい配置 |

## 未確認のこと (2026-09-27 時点)

- ボーカル／楽器の自動判定の精度
- リアルタイムのループ試聴の音質
- スマホ実機での操作、自動保存・復元の動作
