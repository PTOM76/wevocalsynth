# 使い方
WeVocalSynth の操作方法をまとめた説明書。音声ファイルを開いて、ピッチ（音の高さ）や長さを変え、書き出すまでの流れと、各機能の使い方が分かる。

ブラウザだけで動き、音声はパソコン・スマホの外に送られない。

## 用語

| 用語 | 意味 |
| --- | --- |
| ピッチ | 音の高さ。「半音」単位で上げ下げする（12 半音 = 1 オクターブ） |
| フォルマント | 声質（声の太さ・細さ）を決める成分。ピッチだけを上げると声が細く（子どもっぽく）なるので、保持すると自然になる |
| 選択範囲 | 波形の上でドラッグして選んだ部分。加工や音量の操作は、選択範囲があればそこだけ、なければ全体にかかる |
| 原音 / 加工後 | 開いたままの音声と、加工を重ねた音声。ステータスバー（PC）で切り替えて聴き比べられる |
| トラック | 1 つの作業の中に並べる音声。ファイルを追加したり、ボーカルと伴奏に分けたりすると増える。編集できるのは選んでいる 1 本だけで、ほかのトラックは一緒に鳴る |
| 帯パネル | 縦に並べて表示する欄の総称。波形パネル・スペクトログラムパネル・ピッチパネル・音量パネル・フォルマントパネルがあり、それぞれ出す・隠すを選べる |

## 基本の流れ

1. **開く**: 音声ファイルを画面にドラッグ＆ドロップするか、「ファイル → 開く…」（Ctrl+O）。WAV・MP3・M4A などブラウザが再生できる形式と、プロジェクトファイル（.wvsp）が開ける。読み込み中は進捗が出て、× で中断できる
2. **範囲を選ぶ**: 波形の上でドラッグする。選ばなければ全体が対象になる
3. **加工する**: インスペクタの「加工」でピッチ・長さ・フォルマントを決める
4. **聴く**: 「試聴」で加工後の音を聴く（20 秒までの範囲）。「ループ」なら範囲を繰り返し再生しながら、スライダーの変更がすぐ反映される（簡易的な音質）
5. **適用する**: 「適用」で選択範囲に反映する。元に戻す（Ctrl+Z）で取り消せる
6. **書き出す**: 「ファイル → 音声ファイルを書き出す…」で WAV・MP3・Opus に保存する

作業の途中はブラウザ内に自動保存され、次に開いたときに復元される（設定で切れる）。

音声を開いている間に別の音声ファイルをドロップすると、新しいトラックとして追加される（プロジェクトファイルは開き直す）。

## 波形の操作

| 操作 | 動作 |
| --- | --- |
| 波形をドラッグ | 範囲を選ぶ |
| Ctrl（⌘）+ ドラッグ | 範囲を追加する（複数の範囲をまとめて加工できる） |
| 範囲の端をドラッグ | 範囲を広げる・狭める |
| Shift + 範囲の右端をドラッグ | 範囲をその長さまで伸縮する（ピッチは変わらない） |
| 波形をクリック | 再生位置を移す |
| 上の時間目盛りをクリック・ドラッグ | 再生位置を移す（範囲は選ばない） |
| ホイール | 左右に移動。Ctrl + ホイールで拡大・縮小 |
| 右クリック（スマホは長押し） | メニュー（範囲の試聴、切り取り・コピー、ボーカル抽出など。ピッチパネルではピッチの強制表示も） |

![範囲を選んで右クリックしたところ](images/context.png)

スマホでは、波形を 2 本指でピンチすると横に拡大・縮小する。上の時間目盛りは、タップで再生位置へ、ドラッグで再生位置を動かし（端まで行くと表示が流れる）、動かさずに長押しすると横移動になる。

選択範囲の開始・終了は、ステータスバー（スマホは波形の下）の「選択範囲」を押すと数値で入力できる。

## 帯パネルの表示

ツールバー（または「表示」メニュー）で、各パネルを出す・隠すを選ぶ。上から次の順に並ぶ。どれか 1 つは必ず出ている。

| パネル | 内容 |
| --- | --- |
| 波形パネル | 音の大きさの形。範囲を選ぶ・再生位置を動かすのはここで行う |
| スペクトログラムパネル | 周波数ごとの強さを色で表す |
| ピッチパネル | 声の高さの線と、描いた目標のピッチ（[ピッチの編集](#ピッチの編集)） |
| 音量パネル | 描いた音量の曲線（[音量パネル](#音量パネル)） |
| フォルマントパネル | 描いたフォルマントのずらし量（[フォルマント](#フォルマント)） |

![波形パネルとスペクトログラムパネルを出したところ](images/spectrogram.png)

押したパネルにフォーカスが移る（左端に色の線が出る）。ツールバーのパネルごとの操作と、切り取り・コピー・貼り付けは、フォーカスしているパネルに効く。たとえばピッチパネルにフォーカスして Ctrl+C を押すと、音声ではなくピッチの線がコピーされる。

波形・スペクトログラムパネルと、ピッチ・音量・フォルマントパネルの境目をドラッグすると、高さの配分を変えられる。

## 加工

| 項目 | 内容 |
| --- | --- |
| 処理モード | 「ボーカル」は声など単音向け、「楽器」は和音や打楽器向け。ファイルを開いたときに自動で判定される。「…」から細かい処理方式も選べる |
| ピッチ | 半音単位で上げ下げする（小数も可）。範囲の今の音程と、変更後の音名が表示される。「音程を合わせる」で変更後の音程を最寄りの音名に合わせる |
| 長さ | 倍率で伸ばす・縮める（ピッチは変わらない） |
| フォルマント | 「保持」で声質を変えずにピッチだけを変える。「高さ」で声質だけを高く・低くする |

### 処理方式（「…」から選ぶ）

| 方式 | 向いているもの |
| --- | --- |
| ボーカル（PSOLA） | 声。声の周期に合わせて切り貼りする。ボーカルの既定 |
| クロスフェード（SOLA） | 声・単音。短いクロスフェードでつなぐので音のにじみが少ない |
| WSOLA | 子音の多い音声。処理が速い |
| Phase Vocoder | 和音・楽器。滑らかに伸ばす。楽器の既定 |

## ピッチの編集

表示の切り替えで「ピッチ」を ON にすると、波形の下にピッチパネルが出て、声の高さが線で表示される（音名の目盛り付き）。境目をドラッグすると高さを変えられる。

### ペンで描く

ペンのボタンを ON にしてピッチパネルをドラッグすると、目標のピッチを青い線で描ける。

![ピッチパネルだけを出し、2つ目のフレーズのピッチを描き直したところ。ツールバーにピッチの道具と、試聴・適用・破棄が並ぶ](images/pitch.png)

| 操作 | 動作 |
| --- | --- |
| ドラッグ | 描く |
| Shift + ドラッグ | 半音に合わせて描く |
| Alt + ドラッグ | 消す |

### まとめて加工する

ツールバーのボタンで、選択範囲（なければ全体）のピッチをまとめて加工できる。結果は青い線で出るので、確かめてから「適用」する。

| ボタン | 動作 |
| --- | --- |
| ↑ / ↓ | 半音上げる・下げる。キーボードの ↑↓ でも同じ（Shift+↑↓ で 0.1 半音） |
| 平らにする | 揺れ（ビブラート）をならして取り除く |
| 音程に揃える… | 音ごとに近い半音へ、または指定した音（C4 など）へ揃える。揺れを残すか、強さ（%）も選べる |
| ビブラート… | 深さ・速さ・かかり始めの遅れを決めて揺れを加える。速さは設定の BPM に合わせた値が初期値になる |
| 🎧（試聴） | 適用する前に、線を描いた部分を加工して聴く |
| 適用 / 🗑 | 音に反映する / 線を消す |

### ピッチがうまく取れないとき

範囲を選んで右クリックし、「選択範囲のピッチを強制表示」で声のない所にもピッチを出せる（前後の高さから補う）。誤って拾ったピッチは「強制非表示」で消せる。

## 音量

選択範囲（なければ全体）に、ゲイン（dB）、フェードイン・フェードアウト、ノーマライズ（最大音量を -1dB に揃える）、無音化をかける。

### 音量パネル

ツールバーの「音量表示」で音量パネルを出し、ペンで音量の曲線（-24〜+12dB）を描ける。描いた音量は再生にすぐ反映される。「適用」で音に書き込み、🗑 で消す。Shift + ドラッグで 1dB 刻み、Alt + ドラッグで元の音量に戻す。

## フォルマント

![音量パネル（上）とフォルマントパネル（下）に曲線を描いたところ](images/curves.png)

ツールバーの「フォルマント表示」でフォルマントパネルを出し、ペンでフォルマントのずらし量（±12 半音）を描ける。声の高さはそのままで、声質（太さ・細さ）だけが変わる。再生にはすぐ反映されないので、🎧（試聴）で加工して聴いてから「適用」する。Shift + ドラッグで半音刻み、Alt + ドラッグで元に戻す。

## トラック

複数の音声を並べて、一緒に鳴らしながら編集できる。トラックが 2 本以上あるときだけ、ツールバーの下にトラックの欄が出る。

![トラックが 2 本あるときの画面（番号は下の表と対応）](images/tracks_with_note.png)

| 番号 | 内容 |
| --- | --- |
| 1 | トラックの名前と、トラックごとのレベルメーター。選んでいるトラックは明るく、左端に色の線が付く |
| 2 | M（ミュート） |
| 3 | S（ソロ） |
| 4 | 欄を折りたたむ（タブの表示にする）・広げる |
| 5 | トラックの波形（下の大きな波形と同じ範囲）。鳴らないトラックは薄く出る |

| 操作 | 動作 |
| --- | --- |
| トラックを押す | そのトラックを編集する（下の大きな波形がそのトラックになる） |
| Ctrl（⌘）+ 押す / Shift + 押す | 複数選ぶ（Ctrl は 1 本ずつ足す・外す、Shift は範囲） |
| ドラッグ | 並び替える（元に戻せる） |
| M / S | ミュート（鳴らさない）/ ソロ（それだけ鳴らす） |
| 右クリック | 名前の変更・複製・ボーカルと伴奏に分ける・下と統合・すべて統合・ほかのトラックを重ねて表示・削除。複数選んでいるときは、統合・ミュート・ソロ・削除をまとめて行う |

トラックを足すには、「ファイル → ファイルをトラックとして追加…」か、音声ファイルをドロップする。インスペクタの「音量」の「トラック」で、トラックごとの音量（ゲイン）とパンを決める。これは音声を書き換えず、再生と書き出しにそのまま効く。

書き出すと、鳴っているトラック（ミュート・ソロに従う）を混ぜた 1 つの音声になる。

## ボーカル抽出

曲からボーカルだけを取り出したり、伴奏だけを残したりできる。処理はすべてブラウザの中で行う。

| 操作 | 内容 |
| --- | --- |
| 編集 → ボーカルを抽出 | 選択範囲（なければ全体）を、ボーカルだけにする |
| 編集 → 伴奏だけ残す | 選択範囲（なければ全体）を、伴奏だけにする |
| 編集 → ボーカルと伴奏を別トラックに分ける | トラックを、ボーカルと伴奏の 2 本のトラックに置き換える |

初めて使うときは、抽出に使うデータ（追加機能）のダウンロードを確かめる画面が出る。一度導入すればオフラインでも使え、設定から削除できる。

![ボーカル抽出を初めて使うときの、導入を確かめる画面](images/extract.png)

「設定 → ボーカル抽出」で、次のことを選べる。

| 項目 | 内容 |
| --- | --- |
| モデル | 標準・軽量・高精度。軽いほど速くダウンロードも小さいが、分離の精度は下がる |
| GPU を使う | 対応しているブラウザでは速くなる |
| 高音域を残す | 約 11kHz より上を残す。声は明るくなるが、シンバルなどが混ざりやすい |

## 音声の作成

「ファイル → 音声を作成…」で、加工の素材になる音声を作り、新しいトラックとして追加できる。

| 項目 | 内容 |
| --- | --- |
| 音色 | 声（あ・い・う・え・お）か、楽器（のこぎり波・矩形波・三角波・正弦波） |
| 作る音 | 単音（音高と長さを指定）か、MIDI ファイルのメロディ |
| フォルマント・音量 | 声質と大きさ |
| ビブラート | 揺れの深さ（半音）と速さ（Hz） |

「試聴」で作る前に聴ける。

![音声を作成する画面](images/synth.png)

## テンポ（BPM）と拍の線

ファイルを開くと、テンポが自動で解析され、BPM と 1 拍目の位置が入る（設定で切れる）。解析したテンポは実際の 2 倍や半分になることがあるので、画面下の「120 BPM」を押して、候補から選び直すか、×2・÷2、タップ（拍に合わせてボタンを押す）、数値の入力で直す。

「設定 → プロジェクト」で BPM・1 小節の拍数・1 拍目の位置を決めると、波形に拍の線と小節番号が出る（拍の線を出すかは「設定 → テンポ」）。テンポはプロジェクトごとに保存される。範囲の端や再生位置をドラッグすると拍の線に吸い付く（Alt を押している間は吸い付かない）。

## 操作履歴

「編集 → 操作履歴…」で、これまでの操作が一覧で出る。押した操作の直後の状態へ、まとめて戻る・進むことができる（「開いたとき」を押すと最初に戻る）。

## 保存と書き出し

| 操作 | 内容 |
| --- | --- |
| プロジェクトを保存（Ctrl+S） | 原音・加工後・設定を .wvsp ファイルにまとめて保存する。元に戻す履歴は含まない |
| 音声ファイルを書き出す（Ctrl+Shift+S） | WAV・MP3・Opus で保存する。サンプルレート・チャンネル・範囲（選択範囲のみ）を選べる |

Ctrl+S と Ctrl+Shift+S の割り当ては設定で入れ替えられる。

![音声ファイルを書き出す画面。形式・サンプル形式・サンプルレート・チャンネル・範囲・ファイル名を選ぶ](images/export.png)

プロジェクト名を変えていなければ、書き出すファイル名の初期値は「元のファイル名_wevocal」になる。

プロジェクト名は、画面左下の名前を押すか、「設定 → プロジェクト」で変えられる。書き出すファイルの名前の初期値になる。

## 設定

「ファイル → 設定…」（スマホは ⋮ → 設定）。

![設定画面。左に分類と検索欄、右に項目が並ぶ](images/settings.png)

| 分類 | 項目 |
| --- | --- |
| プロジェクト | プロジェクト名、BPM、1 小節の拍数、1 拍目の位置（ほかの分類と違ってプロジェクトに保存され、変えるとすぐ反映される） |
| 全般 | 自動保存と復元、ファイルを開いたときの処理モード、元に戻せる回数・使うメモリの上限、アップデートの確認 |
| 表示 | テーマ（ライト・ダーク・ブラウザに合わせる）、言語、レベルメーター |
| ピッチ解析 | 解析する音の範囲、声とみなす判定の厳しさ、無音とみなす音量（変えると解析し直す） |
| テンポ | 開いたときの自動解析、拍の線の表示 |
| キー操作 | Ctrl+S の動作 |
| ボーカル抽出 | モデル、GPU、高音域を残す、抽出に使うデータの導入・削除 |
| データ | ブラウザ内の使用量、作業データ・オフライン用キャッシュ・設定の削除 |
| 開発者向け | デバッグ表示（Ctrl+Shift+D でも切り替え） |

### 設定画面の操作

| 操作 | 動作 |
| --- | --- |
| 左上の検索欄 | 項目の名前・説明で探す。一致した分類だけが残り、一致した文字に印が付く。Esc で検索語を消す |
| ↑ / ↓・Home / End | 分類を切り替える（分類の一覧にフォーカスがあるとき） |
| Tab | 分類の一覧から右の項目へ移る |
| Enter | OK（設定を確定して閉じる） |
| Esc | 閉じる（パソコンでは、OK を押さずに閉じると変更は捨てられる） |

スマホでは分類の一覧から各画面へ進む形になり、変更はその場で反映される。

### ダイアログの操作

書き出し・音声の作成・ピッチの道具などのダイアログでは、Enter で主のボタン（書き出す・作成など）、Esc で閉じる。Tab でボタンに移って Enter を押すと、そのボタンが押される。

## 新しいバージョン

新しい版が公開されると、画面の右下に「新しいバージョンがあります」と出る。「更新」を押すと切り替わる（作業は自動保存から復元される）。× で通知を閉じられる。設定 → 全般 の「今すぐ確認」でも確かめられ、新しい版があればそこから更新できる。

## キーボード操作

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+X / C / V | 切り取り / コピー / 再生位置に貼り付け（フォーカスしているパネルが対象。ピッチパネルならピッチの線） |
| Ctrl+A / Esc | すべて選択 / 選択解除 |
| Ctrl+O | 開く |
| ← / → | 再生位置を 1 拍（拍の線を出していなければ 1 秒）動かす。Shift で 0.1 秒 |
| Home / End | 先頭 / 末尾へ |
| Ctrl+E | 書き出し |
| Ctrl+S / Ctrl+Shift+S | プロジェクトを保存 / 書き出し（設定で入れ替え可） |
| ↑ / ↓ | ピッチ表示中: 選択範囲のピッチを半音上下（Shift で 0.1 半音） |

一覧は「ヘルプ → ショートカット」でも見られる。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「試聴」が押せない | 試聴は 20 秒まで・1 範囲のみ。長いときは「ループ」か、そのまま「適用」して聴く |
| 加工後の声がこもる・機械っぽい | 処理方式を変えてみる（「…」）。声なら「フォルマント保持」を ON |
| ピッチの線が途切れる | 声が小さい・かすれている部分は取れないことがある。右クリックの「強制表示」で補う |
| 前の作業が勝手に復元される | 設定の「自動保存と復元」を OFF にする |
