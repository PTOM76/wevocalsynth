## 用語

| 用語 | 意味 |
| --- | --- |
| ピッチ | 音の高さ。「半音」単位で上げ下げする（12 半音 = 1 オクターブ） |
| フォルマント | 声質（声の太さ・細さ）を決める成分 |
| 選択範囲 | 波形の上でドラッグして選んだ部分 |
| 原音 / 加工後 | 開いたままの音声と、加工を重ねた音声 |
| トラック | 1 つの作業の中に並べる音声 |
| 帯パネル | 波形・ピッチなどを縦に並べて表示する欄の総称 |

- ピッチだけを上げると、声が細く（子どもっぽく）なる。フォルマントを保持すると自然になる
- 加工や音量の操作は、選択範囲があればそこだけ、なければ全体にかかる
- 原音と加工後は、ステータスバー（スマホは ⋮ のメニュー）で切り替えて聴き比べられる
- 編集できるトラックは、選んでいる 1 本だけ。ほかのトラックは一緒に鳴る
- 帯パネルは 5 種類ある（[帯パネルの表示](#帯パネルの表示)）

## 基本の流れ

1. **開く**: 音声ファイルを画面にドラッグ＆ドロップするか、「ファイル → 開く…」（Ctrl+O）で開く（[開けるファイル](#開けるファイル)）
2. **範囲を選ぶ**: 波形の上でドラッグする。選ばなければ全体が対象になる
3. **加工する**: インスペクタの「加工」で、ピッチや長さを決める
4. **聴く**: 「試聴」で加工後の音を聴く（20 秒までの範囲）。「ループ」なら範囲を繰り返し再生しながら、スライダーの変更がすぐ反映される（簡易的な音質）
5. **適用する**: 「適用」で選択範囲に反映する。元に戻す（Ctrl+Z）で取り消せる
6. **書き出す**: 「ファイル → 音声ファイルを書き出す…」で、音声ファイルに保存する

作業の途中はブラウザの中に自動で保存され、次に開いたときに戻る（[オフラインとデータの保存](#オフラインとデータの保存)）。

## 開けるファイル

| 種類 | 例 |
| --- | --- |
| 音声ファイル | WAV、MP3、M4A（AAC）など、ブラウザが再生できる形式 |
| 動画ファイル | MP4（中の音声だけを読み込む） |
| プロジェクトファイル | .wvsp（このアプリで保存したもの） |

- FLAC や OGG などは、ブラウザによって開けたり開けなかったりする
- 大きなファイルは、読み込み中に進捗が出る。× で中断できる
- 音声を開いている間に別の音声ファイルをドロップすると、新しいトラックとして追加される

## オフラインとデータの保存

- 音声はパソコンやスマホの外に送られない。処理はすべてブラウザの中で行う
- 一度開いたあとは、ネットにつながっていなくても使える
- ブラウザの「インストール」（ホーム画面に追加）で、アプリのように起動できる
- 作業の途中はブラウザの中に自動で保存され、次に開いたときに戻る（「設定 → 全般」で切れる）
- 保存したデータは「設定 → データ」で確認・削除できる

## 波形の操作

| 操作 | 動作 |
| --- | --- |
| 波形をドラッグ | 範囲を選ぶ |
| Ctrl（⌘）+ ドラッグ | 範囲を追加で選ぶ |
| 範囲の端をドラッグ | 範囲を広げる・狭める |
| Shift + 範囲の右端をドラッグ | 範囲の音声を、その長さに伸び縮みさせる |
| 波形をクリック | 再生位置をそこへ移す |
| 時間目盛りをクリック・ドラッグ | 再生位置を移す（範囲は選ばない） |
| ホイール | 表示を左右に動かす |
| Ctrl+ホイール | 表示を拡大・縮小する |
| 右クリック（スマホは長押し） | メニューを開く |

- 複数の範囲を選ぶと、まとめて加工できる
- 範囲の伸び縮みでは、ピッチは変わらない

右クリックのメニューには、範囲の試聴、切り取り・コピー、ボーカル抽出などが並ぶ。ピッチパネルで右クリックすると、ピッチの強制表示も出る。

<img src="images/context.png" alt="範囲を選んで右クリックしたところ" width="360">

スマホでは、波形を 2 本指でピンチすると横に拡大・縮小する。上の時間目盛りは、タップで再生位置へ、ドラッグで再生位置を動かし（端まで行くと表示が流れる）、動かさずに長押しすると横移動になる。

選択範囲の開始・終了は、ステータスバー（スマホは波形の下）の「選択範囲」を押すと数値で入力できる。

## 帯パネルの表示

ツールバー（または「表示」メニュー）で、各パネルを出す・隠すを選ぶ。上から次の順に並ぶ。どれか 1 つは必ず出ている。

| パネル | 内容 |
| --- | --- |
| 波形パネル | 音の大きさの形。範囲を選ぶ・再生位置を動かすのはここで行う |
| スペクトログラムパネル | 周波数ごとの強さを色で表す |
| ピッチパネル | 声の高さの線と、描いた目標のピッチ（[ピッチの編集](#ピッチの編集)） |
| 音量パネル | 描いた音量の曲線（[音量パネル](#音量パネル)） |
| フォルマントパネル | 描いたフォルマントのずらし量（[フォルマント](#フォルマント)） |

<img src="images/spectrogram.png" alt="波形パネルとスペクトログラムパネルを出したところ" width="800">

押したパネルにフォーカスが移る（左端に色の線が出る）。ツールバーのパネルごとの操作と、切り取りやコピーは、フォーカスしているパネルに効く。たとえばピッチパネルにフォーカスして Ctrl+C を押すと、音声ではなくピッチの線がコピーされる。

上のパネル（波形とスペクトログラム）と下のパネル（ピッチ、音量、フォルマント）の境目をドラッグすると、高さの配分を変えられる。

## 加工

| 項目 | 内容 |
| --- | --- |
| 処理モード | 「ボーカル」は声など単音向け、「楽器」は和音や打楽器向け |
| ピッチ | 半音単位で上げ下げする（小数も可） |
| 長さ | 倍率で伸ばす・縮める（ピッチは変わらない）。×0.5〜×4 のボタンでも選べる |
| フォルマント | 「保持」で声質を保つ。「高さ」で声質だけを変える |

- 処理モードは、ファイルを開いたときに自動で判定される。「…」から細かい処理方式も選べる
- ピッチの下には、範囲の今の音程と変更後の音名が出る。磁石のボタンで、変更後の音程を最寄りの音名に合わせる

加工の欄の下のボタン:

| ボタン | 動作 |
| --- | --- |
| 試聴 | 加工した音を聴く（20 秒までの範囲） |
| ループ | 範囲を繰り返し再生する。スライダーを動かすと、すぐ音に反映される（簡易的な音質） |
| ↺（リセット） | ピッチ・長さ・フォルマントの値を元に戻す |
| 適用 | 選択範囲（なければ全体）に加工を反映する |

### 処理方式（「…」から選ぶ）

| 方式 | 向いているもの |
| --- | --- |
| ボーカル（PSOLA） | 声。声の周期に合わせて切り貼りする。ボーカルの既定 |
| クロスフェード（SOLA） | 声・単音。短いクロスフェードでつなぐので音のにじみが少ない |
| WSOLA | 子音の多い音声。処理が速い |
| Phase Vocoder | 和音・楽器。滑らかに伸ばす。楽器の既定 |

## ピッチの編集

表示の切り替えで「ピッチ」を ON にすると、波形の下にピッチパネルが出て、声の高さが線で表示される（音名の目盛り付き）。境目をドラッグすると高さを変えられる。

### ペンで描く

ペンのボタンを ON にしてピッチパネルをドラッグすると、目標のピッチを青い線で描ける。

<img src="images/pitch.png" alt="ピッチパネルだけを出し、2つ目のフレーズのピッチを描き直したところ。ツールバーにピッチの道具が並ぶ" width="800">

| 操作 | 動作 |
| --- | --- |
| ドラッグ | 描く |
| Shift + ドラッグ | 半音に合わせて描く |
| Alt + ドラッグ | 消す |

### まとめて加工する

ツールバーのボタンで、選択範囲（なければ全体）のピッチをまとめて加工できる。結果は青い線で出るので、確かめてから「適用」する。

| ボタン | 動作 |
| --- | --- |
| ↑ / ↓ | 半音上げる・下げる |
| 平らにする | 揺れ（ビブラート）をならして取り除く |
| 音程に揃える… | 近い半音や、指定した音（C4 など）に揃える |
| ビブラート… | 深さと速さを決めて、揺れを加える |
| MIDI の音程を当てはめる… | MIDI ファイルのメロディの音程に合わせる |
| 🎧（試聴） | 適用する前に、線を描いた部分を加工して聴く |
| 適用 / 🗑 | 音に反映する / 線を消す |

ビブラートの速さは、プロジェクトの BPM に合わせた値が初めに入る。

「MIDI の音程を当てはめる」で選べるもの:

| 項目 | 内容 |
| --- | --- |
| MIDI ファイル | 当てはめるメロディのファイル |
| トラック | MIDI の中のどのトラックを使うか |
| 開始位置 | MIDI の 1 音目を、音声のどこに合わせるか（秒） |
| テンポ | MIDI のテンポのままか、プロジェクトの BPM に合わせるか |
| 移調 | MIDI の音程を半音単位でずらす |
| 揺れを残す・強さ | 元の歌い方の揺れをどれだけ残すか |

### ピッチがうまく取れないとき

範囲を選んで右クリックし、「選択範囲のピッチを強制表示」で声のない所にもピッチを出せる（前後の高さから補う）。誤って拾ったピッチは「強制非表示」で消せる。

## 音量

インスペクタの「音量」には、3 つの欄がある。

| 欄 | 内容 |
| --- | --- |
| トラック | トラック全体の音量（ゲイン）とパン。音声は書き換えず、再生と書き出しにそのまま効く |
| 選択範囲 | 範囲の音量とパン。動かすと再生にすぐ反映され、「適用」で音声に書き込む（範囲を選んでいるときだけ出る） |
| ボタン | 選択範囲（なければ全体）に、すぐかける |

| ボタン | 動作 |
| --- | --- |
| フェードイン | だんだん大きくする |
| フェードアウト | だんだん小さくする |
| ノーマライズ | いちばん大きい所を -1 dB に揃える |
| 無音化 | 音を消す |

### 音量パネル

ツールバーの「音量表示」で音量パネルを出し、ペンで音量の曲線（-24〜+12dB）を描ける。描いた音量は再生にすぐ反映される。「適用」で音に書き込み、🗑 で消す。Shift + ドラッグで 1dB 刻み、Alt + ドラッグで元の音量に戻す。

## フォルマント

<img src="images/curves.png" alt="音量パネル（上）とフォルマントパネル（下）に曲線を描いたところ" width="800">

ツールバーの「フォルマント表示」でフォルマントパネルを出し、ペンでフォルマントのずらし量（±12 半音）を描ける。声の高さはそのままで、声質（太さ・細さ）だけが変わる。再生にはすぐ反映されないので、🎧（試聴）で加工して聴いてから「適用」する。Shift + ドラッグで半音刻み、Alt + ドラッグで元に戻す。

## トラック

複数の音声を並べて、一緒に鳴らしながら編集できる。トラックが 2 本以上あるときだけ、ツールバーの下にトラックの欄が出る。

<img src="images/tracks_with_note.png" alt="トラックが 2 本あるときの画面（番号は下の表と対応）" width="800">

| 番号 | 内容 |
| --- | --- |
| 1 | トラックの名前と音量メーター。編集しているトラックは明るく出る |
| 2 | M（ミュート）: このトラックを鳴らさない |
| 3 | S（ソロ）: このトラックだけを鳴らす |
| 4 | トラックの欄を折りたたむ（タブの表示にする）・広げる |
| 5 | トラックの波形。鳴らないトラックは薄く出る |

| 操作 | 動作 |
| --- | --- |
| トラックを押す | そのトラックを編集する |
| Ctrl（⌘）+ 押す | トラックを 1 本ずつ選び足す・外す |
| Shift + 押す | 編集しているトラックから、押したトラックまでをまとめて選ぶ |
| ドラッグ | トラックを並び替える |
| 右クリック | トラックのメニューを開く |

トラックのメニューでできること:

- 名前の変更、複製、削除
- ボーカルと伴奏に分ける
- すぐ下のトラックと統合する、すべて統合する
- ほかのトラックの波形を、大きな波形の後ろに重ねて表示する

複数選んで右クリックすると、統合、ミュート、ソロ、削除をまとめて行える。並び替えは元に戻せる。

トラックを足すには、「ファイル → ファイルをトラックとして追加…」か、音声ファイルをドロップする。インスペクタの「音量」の「トラック」で、トラックごとの音量（ゲイン）とパンを決める。これは音声を書き換えず、再生と書き出しにそのまま効く。

書き出すときは、全トラックを混ぜるか、選んでいるトラックだけにするかを選べる（[保存と書き出し](#保存と書き出し)）。

## ボーカル抽出

曲からボーカルだけを取り出したり、伴奏だけを残したりできる。処理はすべてブラウザの中で行う。

| 操作 | 内容 |
| --- | --- |
| 編集 → ボーカルを抽出 | 選択範囲（なければ全体）を、ボーカルだけにする |
| 編集 → 伴奏だけ残す | 選択範囲（なければ全体）を、伴奏だけにする |
| 編集 → ボーカルと伴奏を別トラックに分ける | トラックを、ボーカルと伴奏の 2 本のトラックに置き換える |

初めて使うときは、抽出に使うデータ（追加機能）のダウンロードを確かめる画面が出る。一度導入すればオフラインでも使え、設定から削除できる。

<img src="images/extract.png" alt="ボーカル抽出を初めて使うときの、導入を確かめる画面" width="380">

「設定 → ボーカル抽出」で、次のことを選べる。

| 項目 | 内容 |
| --- | --- |
| 利用するモデル | 標準、軽量、高精度から選ぶ。軽いほどダウンロードが小さいが、分離の精度は下がる |
| GPU処理を利用する | 対応しているブラウザでは速くなる |
| 高音域を残す | 約 11kHz より上を残す。声は明るくなるが、シンバルなどが混ざりやすい |

## 音声の作成

「ファイル → 音声を作成…」で、加工の素材になる音声を作り、新しいトラックとして追加できる。

| 項目 | 内容 |
| --- | --- |
| 音色 | 声（あいうえお）か、楽器（4 種類の波形） |
| 作る音 | 単音（音高と長さを指定）か、MIDI ファイルのメロディ |
| フォルマント・音量 | 声質と大きさ |
| ビブラート | 揺れの深さ（半音）と速さ（Hz） |

「試聴」で作る前に聴ける。

<img src="images/synth.png" alt="音声を作成する画面" width="380">

## テンポ（BPM）と拍の線

ファイルを開くと、テンポが自動で解析され、BPM と 1 拍目の位置が入る（設定で切れる）。解析したテンポは、実際の 2 倍や半分になることがある。画面下の BPM の表示（「120 BPM」など）を押すと、次の方法で直せる。

| 方法 | 内容 |
| --- | --- |
| 候補から選ぶ | 自動解析で見つかった候補から選ぶ |
| ×2 / ÷2 | 今の BPM を 2 倍・半分にする |
| タップで計測 | 拍に合わせて押した間隔から BPM を求める |
| 数値で入力 | BPM を直接入れる |
| 再解析 | もう一度自動で解析する |

「設定 → プロジェクト」で BPM、拍子、1 拍目の位置を決めると、波形に拍の線と小節番号が出る（拍の線を出すかは「設定 → テンポ」）。テンポはプロジェクトごとに保存される。範囲の端や再生位置をドラッグすると拍の線に吸い付く（Alt を押している間は吸い付かない）。

## 操作履歴

「編集 → 操作履歴…」で、これまでの操作が一覧で出る。押した操作の直後の状態へ、まとめて戻る・進むことができる（「開いたとき」を押すと最初に戻る）。

## 保存と書き出し

| 操作 | 内容 |
| --- | --- |
| プロジェクトを保存（Ctrl+S） | 作業をまとめて .wvsp ファイルに保存する |
| 音声ファイルを書き出す（Ctrl+Shift+S） | 音声をファイルに保存する |

- プロジェクトには、原音、加工後の音声、設定が入る。元に戻す履歴は入らない
- トラックが 2 本以上あるときは、「全トラックのミックス」か「選んでいるトラックだけ」かを選べる。ミックスは、鳴っているトラック（ミュート・ソロに従う）を混ぜた 1 つの音声になる

書き出せる形式:

| 形式 | 拡張子 | 選べるもの |
| --- | --- | --- |
| WAV | .wav | 16-bit / 24-bit / 32-bit float |
| MP3 | .mp3 | 96〜320 kbps。サンプルレートは 32 / 44.1 / 48 kHz |
| Opus | .ogg | 64〜256 kbps。48 kHz 固定。対応しているブラウザだけ |

形式のほかに、サンプルレート、モノラルにするか、範囲（全体か選択範囲だけか）、ファイル名を選ぶ。

Ctrl+S と Ctrl+Shift+S の割り当ては設定で入れ替えられる。

<img src="images/export.png" alt="音声ファイルを書き出す画面" width="380">

プロジェクト名は、画面左下の名前を押すか、「設定 → プロジェクト」で変えられる。書き出すファイル名の初期値はプロジェクト名になる（名前を変えていなければ「元のファイル名_wevocal」）。

## 設定

「ファイル → 設定…」（スマホは ⋮ → 設定）。

<img src="images/settings.png" alt="設定画面。左に分類と検索欄、右に項目が並ぶ" width="640">

| 分類 | 項目 |
| --- | --- |
| プロジェクト | プロジェクト名、BPM、拍子、1 拍目の位置 |
| 全般 | 自動保存、開いたときの処理モード、元に戻せる回数、更新の確認 |
| 表示 | テーマ（ライト、ダーク、ブラウザに合わせる）、言語、音量メーター |
| ピッチ解析 | 解析する音の範囲、声とみなす判定の厳しさ、無音とみなす音量（変えると解析し直す） |
| テンポ | 開いたときの自動解析、拍の線の表示 |
| キー操作 | Ctrl+S の動作 |
| ボーカル抽出 | モデル、GPU、高音域を残す、抽出に使うデータの導入・削除 |
| データ | ブラウザ内の使用量の確認と、保存したデータの削除 |
| 開発者向け | デバッグ表示（Ctrl+Shift+D でも切り替え） |

### 設定画面の操作

| 操作 | 動作 |
| --- | --- |
| 検索欄に入力 | 名前や説明に一致する項目を探す |
| ↑ / ↓・Home / End | 分類を切り替える（分類の一覧にフォーカスがあるとき） |
| Tab | 分類の一覧から右の項目へ移る |
| Enter | OK（設定を確定して閉じる） |
| Esc | 検索語を消す。検索語が無ければ、設定画面を閉じる |

- パソコンでは、OK を押さずに閉じると、変えた内容は捨てられる
- スマホでは、分類の一覧から各画面へ進む。変えた内容はその場で反映される
- 「プロジェクト」の分類だけは、パソコンでも変えた時点で反映される

### ダイアログの操作

書き出しや音声の作成などのダイアログでは、Enter で主のボタン（「書き出す」「作成」など）を押し、Esc で閉じる。Tab でボタンに移って Enter を押すと、そのボタンが押される。

## 新しいバージョン

新しい版が公開されると、画面の右下に「新しいバージョンがあります」と出る。「更新」を押すと切り替わる（作業は自動保存から復元される）。× で通知を閉じられる。設定 → 全般 の「今すぐ確認」でも確かめられ、新しい版があればそこから更新できる。

## キーボード操作

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+X / C / V | 切り取り / コピー / 再生位置に貼り付け |
| Ctrl+A / Esc | すべて選択 / 選択解除 |
| Ctrl+O | 開く |
| ← / → | 再生位置を 1 拍ずつ動かす |
| Shift+← / → | 再生位置を 0.1 秒ずつ動かす |
| Home / End | 再生位置を先頭 / 末尾へ移す |
| Ctrl+E | 音声ファイルを書き出す |
| Ctrl+S / Ctrl+Shift+S | プロジェクトを保存 / 音声ファイルを書き出す |
| ↑ / ↓ | 選択範囲のピッチを半音上げる / 下げる（ピッチパネルを出しているとき） |
| Shift+↑ / ↓ | 選択範囲のピッチを 0.1 半音上げる / 下げる |

- 切り取り、コピー、貼り付けは、フォーカスしているパネルにかかる。ピッチパネルなら、ピッチの線が対象になる
- ← / → は、拍の線を出していないときは 1 秒ずつ動かす
- Ctrl+S と Ctrl+Shift+S の割り当ては、設定で入れ替えられる

一覧は「ヘルプ → ショートカット」でも見られる。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「試聴」が押せない | 範囲を 20 秒以内・1 つにする。長いときは「ループ」で聴く |
| 加工後の声がこもる・機械っぽい | 処理方式を変えてみる（「…」）。声なら「フォルマント保持」を ON |
| ピッチの線が途切れる | 範囲を選び、右クリックの「選択範囲のピッチを強制表示」で補う |
| 前の作業が勝手に復元される | 「設定 → 全般」の「作業を自動保存し、次回開いたときに復元する」を OFF にする |
| ボーカル抽出で声と伴奏がうまく分かれない | 「設定 → ボーカル抽出」でモデルを「高精度」に変える |
| 抽出した声にシンバルなどが混ざる | 「高音域を残す」を OFF にする |
| 抽出した声がこもって聞こえる | 「高音域を残す」を ON にする |
| ボーカル抽出が遅い | モデルを「軽量」にするか、「GPU処理を利用する」を ON にする |
| ボーカル抽出が失敗する・結果がおかしい | 「GPU処理を利用する」を OFF にする。スマホではモデルを「軽量」にする |
| ファイルが開けない | WAV か MP3 に変換してから開く |
